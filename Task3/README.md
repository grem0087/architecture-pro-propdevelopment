# Требования к системе "умный дом"

## Требования к безопасности

* Все данные должны передаваться в зашифрованном виде
* Все действия входящих/исходящих соединений должны журналироваться с фиксацией источника и приемника
* Все входящие запросы должны быть закрыты авторизацией
* Необходимо соответствовать требованиям 152-ФЗ "О персональных данных"
* Необходимо переодически обновлять ключи шифрования (токены)
* Так как нет необходимости прямого доступа к сервисам "умного дома" (а возможно и нектороым другим внутренним системам) компании из вне (клиенты управляют им через сервис tenant-core-app, а внешние системы интегрированы через Gateway) - их можно разместить в закрытом контуре за реверс прокси.

##  Протоколы аутентификации и авторизации

* Необходимо использовать протокол TLS 1.2 или выше
* Входящее соединение осуществлять с использованием токена(AccessToken) или авторизации. Если необходимо прямое обращение польз-ей к сервисам, можно использовать OAuth 2.

## Взаимодействие между системами и внешними платформами

* Взаимодействие с внешними платформами организуется через REST API.
* Взаимодействие с моб. приложением и сайтом организуется через REST API.
* Внутреннее взаимодействие (межсервисное) лучше организовать через gRPC (увеличение скорости передачи данных).
